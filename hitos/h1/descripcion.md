# H1 – Mi proceso lento: Control de deudas de clientes

El negocio se dedica a la venta mayorista de calzados para mujeres.
Actualmente, el registro de las deudas de los clientes se realiza manualmente en cuadernos.
Cada vez que un cliente realiza una compra y queda pendiente de pago, se registra la información correspondiente.
Una encargada del taller es responsable de registrar y controlar los pagos.
Cuando un cliente realiza un abono, se actualiza manualmente el monto pendiente.
El problema aparece cuando se necesita consultar cuánto debe un cliente.
Para encontrar la información, la encargada debe revisar las anotaciones del cuaderno.
También puede ser necesario revisar registros anteriores para comprobar los pagos realizados.
Esta búsqueda suele tardar aproximadamente un minuto por consulta.
Cuando existen varias consultas, el trabajo se vuelve repetitivo y consume tiempo.
Además, el manejo manual puede ocasionar errores al calcular o actualizar las deudas.
Por esta razón, se busca una forma de organizar la información que permita encontrar los datos más rápidamente.
