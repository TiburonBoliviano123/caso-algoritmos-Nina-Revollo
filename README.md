# Análisis de Algoritmos – Caso Integrador

**Estudiante:** Brayan Rodrigo Nina Revollo

**Proyecto:** Análisis de procesos y estructuras de datos en una zapatería mayorista.

## Descripción del proyecto

Este repositorio contiene el desarrollo de las actividades de la materia de Análisis de Algoritmos. Se utiliza como caso de estudio un pequeño negocio familiar dedicado a la venta mayorista de calzados para mujeres.

El objetivo es identificar procesos que actualmente se realizan de forma manual, analizar sus dificultades y estudiar cómo pueden mejorarse mediante algoritmos y estructuras de datos.
