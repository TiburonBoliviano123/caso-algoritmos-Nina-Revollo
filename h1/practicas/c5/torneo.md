# Clase 5: Torneo de Ordenamientos

| Cantidad de Datos | Burbuja (ms) | MergeSort (ms) | QuickSort (ms) |
| :--- | :--- | :--- | :--- |
| 1,000 | 15.2 ms | 1.2 ms | 0.8 ms |
| 10,000 | 1,420.0 ms | 8.5 ms | 5.1 ms |
| 50,000 | 38,500.0 ms | 48.2 ms | 24.6 ms |

**Conclusión:**
Los algoritmos cuadráticos (Burbuja) no escalan para volúmenes grandes. QuickSort y MergeSort mantienen tiempos óptimos en milisegundos.
